# Toggle

Interrupteur pour un réglage activé immédiatement.

**Origine :** Proposé.

## Quand l'utiliser

Réglage binaire à effet immédiat (utiliser mes points). Pour un formulaire à valider, `Checkbox`.

## Variantes

Une seule.

## États

Off (`surface-raised`) · On (`primary`) · Focus · Disabled.

## Responsive

Taille fixe 52 × 30.

## Règles de composition

- `role="switch"` ; libellé qui décrit l'état activé.

## Exemple

```jsx
<Toggle label="Utiliser mes points de fidélité" />
```
