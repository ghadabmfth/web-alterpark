# StoreBadges

Badges officiels Google Play et App Store.

**Origine :** Observé : 223 × 74, écart 30 px.

## Quand l'utiliser

Section de l'application mobile.

## Variantes

Liens `googlePlayHref`, `appStoreHref`.

## États

Survol : léger soulèvement ; focus `shadow-focus`.

## Responsive

56 px de haut sous 576 px.

## Règles de composition

- Ne pas modifier les badges (chartes Google et Apple).

## Exemple

```jsx
<StoreBadges googlePlayHref="…" appStoreHref="…" />
```
